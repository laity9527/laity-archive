# 竞品差距与优化建议（2026-11-16）

评审人：AI（产品视角）
方法：本项目 1440×900 实拍（首页 / 大厅 / 详情 / 标签 / 归档 / 作品 / 登录）+ 本会话已完成的后台 DOM 自查；
竞品侧按**产品形态分类**比较（不是逐家抄功能），每类只取"它做对了什么"。
局限：后台视觉细节未在本轮实拍（需登录）；`/logs` 在无头浏览器里受 PPR 揭示限制，按服务端 HTML 与人工确认结果判断。

---

## 一、先定位：我们不是哪一类产品

竞品可分四类，Laity 只与其中两类真正可比：

| 类别 | 代表 | 与我们的关系 |
|---|---|---|
| 身份卡/履历 | GitHub Profile、Read.cv 类 | **弱可比**：它们卖"被招聘方看见"，我们卖"可核对的工程判断" |
| 个人博客/静态站 | Bear Blog、Ghost、Hugo/Astro 主题 | **强可比**：排版、阅读、订阅、搜索是同一张考卷 |
| 知识库/双链 | Obsidian Publish、Quartz | **中可比**：它们做"内容之间连起来"，我们目前是"按时间/标签平铺" |
| 开发者社区 | Dev.to、Hashnode | **不可比**：社区靠流量与互动，我们明确无 UGC |

**结论**：真正要补的差距，来自"博客/静态站"与"知识库"这两类；与社区类比互动是自找麻烦。

---

## 二、我们明显领先的地方（别为了对标砍掉）

| 能力 | 我们 | 多数个人站 |
|---|---|---|
| 内容可核对 | 发布时写 SHA-256 + 服务器时间，详情页可复算 | 无 |
| 订阅格式 | RSS + JSON Feed，且**支持按标签订阅**（两种格式） | 多数只有 RSS |
| 阅读路径 | 目录 + 进度条 + 上下篇 + 相关阅读（同标签优先/同项目兜底） | 多数只有目录 |
| 结构化数据 | canonical + OG article + JSON-LD BlogPosting | 常见缺 JSON-LD |
| 后台写路径 | 双栏 Markdown、工具栏、⌘B/⌘I/⌘K、粘贴上传、自动保存、字数、敏感提示 | 多数是纯 textarea |
| 数据主权 | 自建库 + 全量 JSON 导出 | 平台锁定 |

这些是"克制底子"换来的资产，优化时不应该为了像竞品而稀释。

## 四、明确不建议跟随的竞品动作

| 竞品做法 | 为什么不做 |
|---|---|
| 评论区、点赞、关注 | 与"无 UGC"定位冲突；维护成本与风险（垃圾、合规）远高于收益 |
| 花哨的滚动动效/视差 | 与"档案阅读"气质相反；且拖累性能 |
| 卡片阴影、大圆角、彩色渐变 | 会稀释纸白/墨色的品牌资产 |
| 社交平台式信息流 | 我们是"档案"，不是"动态" |
| 强行上全文检索（Meilisearch 等） | 当前 13 篇；`contains` 足够，等破千再评估 |

## 九、G1 第一刀：正文内链（2026-11-16）

**做了什么**：正文（BEFORE / AFTER / 经验总结）支持 `[[slug]]`，渲染为同作者已发布日志的链接，显示目标标题；
代码块与既有链接内部不接管，未命中（草稿 / 别家 / 写错）保留原文。实现分两层：
`src/lib/log-links.ts`（切分、抽引用、hast 改写，纯函数）→ `src/lib/markdown.tsx`（可选 `logLinks`，
改写发生在 `rehype-sanitize` 之前，清洗仍是唯一边界）。

**为什么没有新增查询**：详情页原本就为前后篇/相关阅读调 `getLogContext`，它已经取出本租户全部已发布日志的
slug + 标题；本轮让它多返回一份 `catalog`，内链目标表直接复用。**详情页 Prisma 调用仍是 2**，
不抬高 B0 验收里的 "≤2" 基线。

**验证**：单测 8 条（切分边界、非法 slug、去重与 50 上限、命中/未命中、代码块与嵌套链接不接管）；
临时探针日志（写入后即删，库内无残留）实测：内链 href 正确、显示目标标题、未命中保留 `[[missing-slug]]`、
代码块内 `[[slug]]` 仍是字面量、没有生成 `/logs/missing-slug` 死链。

**"被引用"为什么留到下一轮**：反向列表必须按 `content contains` 查一次，详情页会从 2 变 3。
虽然仍在 AGENTS 的"任一前台页 ≤3"内，但与 B0 写下的"详情页 ≤2"冲突；在没有你点头前不擅自抬高基线。
裁定：**与 G2 系列 / G8 快照的迁移一起做**——一次迁移、一次预算评审，比现在零散加一条查询干净。

## 十、A2 第二刀：后台列表排序（2026-11-16）

## 十二、A5：登录态草稿预览（2026-11-16）

**做了什么**：新增 `/admin/logs/[id]/preview`。用详情页同一套排版（标题、时间轴、BEFORE / AFTER / 经验总结、
720px 宋体正文、内链解析）渲染**库中当前内容**，顶部一行提示“发布前只有登录可见；发布后才会生成
