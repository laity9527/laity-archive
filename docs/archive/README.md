## 一、进入本目录意味着什么

- 文中结论、数字、路径都可能停留在写作当天，**不得据此改代码或验收**。
- 需要引用历史决策时，引用"结论 + 日期"，不把归档文档当规范。
- 归档文档正文不再改写；只在文件头加封存声明（谁取代、采纳项在哪）。
- 归档文件可以删除的唯一条件：确认无任何代码/文档引用，且有效信息已被现行文档完整吸收。

### 2.1 原型文件的命名例外

`2026-11-16-历史方案与原型/设计可视化快照/` 下保留三种命名：

- 语义名：`laity-design-diagram.html`、`laity-design-v2.html`、`设计升级方案-V3-2026-11-13.html`；
- 哈希名：`snapshot-<sha256>.html`，为导出时的原始快照名，重命名会丢失出处，故保留；
- 早期变体：`设计升级方案-V3-2026-11-13-早期版.html`，与定稿同名文件内容不同，靠后缀区分。

新增归档文件按 `YYYY-MM-DD-主题.扩展名` 命名；上述历史文件名不追溯重命名。
