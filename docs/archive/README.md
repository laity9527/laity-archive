本仓库当前形态为 **V1.0 单人版**：口令登录后台、无注册、无多用户、无付费。实现与设计的依据只有根目录三份受控文档：

- `AGENTS.md` —— 事实基座与视觉铁律
- `DESIGN.md` —— 决策记录（D1–D29）
- `SPEC.md` —— 规格锁定

凡与本目录文件冲突的表述，以上述三份为准；本目录文件描述的功能（注册、多租户、团队协作、付费订阅、GitHub 同步、自定义域名等）一律不实现。
