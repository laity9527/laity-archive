把档案库做成一件档案

现状不是「不好看」，而是太客气：导航 10px、区头 10px、元信息 11px，全站最小的字号承担了最多的信息；留白大于内容，索引系统没有建立。V3 不重做功能，用「编目」把已有的 13 条日志、2 个项目和 56 个标签重新组织成一座可读、可查、可引用的档案馆。

ISSUES.md 中仍开放的问题

A三个判断
01 · 首屏
没有「馆藏规模」

访客看完标语，不知道这里有多少东西、最近有没有更新。首页用整块空白换来了安静，却没有换来信任。

02 · 索引
层级靠颜色，不靠字号

导航 10px、区头 10px、标签 11px，只比正文小 4–8px。扫读时没有一个稳定的「抓手」，所有信息看起来同等重要。

03 · 阅读
读完没有去处

详情页止于摘要印章：没有前后篇、没有相关日志、没有阅读时长。档案的价值不在单篇，而在「串起来」。

B设计主张
INDEX FIRST
索引优先

编号、计数、日期不再是装饰，而是版式构件：01–03 的项目索引、馆藏计数、条目日期都进入网格，而不是散落在灰字里。

PAPER & INK
纸与墨

只有纸白、墨黑、暖线与一枚封泥红。不用阴影、圆角和卡片堆叠制造层次——用 1px 线、字号和留白。

ONE RED MARK
一处红

新增 --seal #a03a33，只给「档案凭据 / 已发布 / 阻断风险」三处。它是印章，不是装饰色。

D为什么是这一版，而不是再加一屏
已交付的 V2 设计图是对的，但太保守

它把改动压在「统计条 / 计数行 / 前后篇」这些补丁上，没有动版式本身。结果是信息更全了，但仍然像博客：小字、横排筛选、没有编目感。

V3 只改「组织方式」

同样的数据、同样的字体、同样的四色，换一套网格与字号阶，观感会从「个人博客」跳到「档案馆」。这是投入产出比最高的一刀。

Design language

纸、墨、线与一枚封泥

保留 D30 已闭环的暖调令牌，只补一枚「封泥红」。字号阶从「能用」提到「可读」：导航 12、正文 16、正文宋体 18/1.85、页标题 56。所有层级先用字号和留白解决，颜色只做最后一层区分。

03版心与节奏
版心 1200 / 1080 / 720

桌面首页与大厅放宽到 1200px（现 1080）；详情页仍 1080 外框 + 720 正文；后台 1200。放宽只发生在「列表型」页面，正文阅读宽度不动。

≤1024px 回落单列；筛选栏变成顶部折叠面板；详情目录收进正文头部。

8px 节奏

页面上下 96 / 72；区块之间 56；列表行 20–24；标题下 12；标签间距 8。所有间距取 4 的倍数，禁止 13、18 这类孤值。

1px 线是唯一分隔手段：区块用墨线（1px），条目用暖线（1px），双线只出现在页头。

1筛选栏：URL 参数不动
  • ?project= / ?tag= / ?q= / ?cursor= 的语义完全不变，只换呈现；可分享、可回退仍然成立。

  • 现状只在空态给「清除筛选」；有结果时看不到筛了什么。V3 把摘要固定在结果区顶部，每个条件可单独 ×。

D30 四步切换：四类漂移点一次改全、回退值要先验框架、对比度只认实算

● BEFORE 2026-11-05● AFTER 2026-11-06约 7 分钟标签 视觉令牌 · WCAG
BEFORE · 当时的判断

视觉令牌切换不是改四个色值，而是四类漂移点：令牌自己、回退字面量、Proxy 内联页、软著材料里的代码。

一、风险不在改值，在「改一处忘一处」

只要有一处仍是字面量，回退值与令牌值就会分叉；分叉不会报错，只会在某个页面悄悄变回旧色。

二、回退值要先验框架行为

var(--color-ink-soft, #5c5c5c) 的回退值在 @theme inline 下是否真的输出，要先看产物 CSS，不能靠推断。

AFTER · 做完的验证

四色全部落地，Proxy 四组字面量同 commit 同步；实算对比度：主墨 15.47:1、辅助灰 5.81:1、棕 5.56:1、暖线 1.33:1（装饰性豁免）。

三、层间区分度要实测，不认设计意图

在三个页面扫描所有直接承载文本的元素，确认没有一处层次只靠 2.66:1 的颜色差承担。

经验总结

视觉切换的返工成本集中在「改了 A 忘了 B」：同一颜色在几个地方各写一遍，就必须用引用制单源 + 同 commit 同步点把它锁死。

不是「看起来变好了」，而是四道门禁全 0、三档断点无溢出、对比度全部达标、软著材料重出且两次 MD5 一致、产出物无凭据。下面是逐项可核对的判据。

GATE 01
四道门禁

npm run lint
npx tsc --noEmit
npm test
npm run build

全 0 退出；测试数从 157 起只增不减。

GATE 02
布局与可达性

390 / 768 / 1440 三档无横向溢出（scrollWidth === innerWidth）；焦点环可见；aria-current 全站唯一；导航可键盘到达。

GATE 03
对比度

正文与链接 ≥ 4.5:1；新增 --seal 实算 5.88:1；1px 装饰线按 I073 豁免，但印章边框（非文本）≥ 3:1。

GATE 04
材料

软著材料重出：assertWindowFit() 放行、两次生成 MD5 一致、收录行无丢失无重复、新增行合法。

GATE 05
凭据与隐私

产出物逐行扫凭据形态；示例串不写真实键；导出 JSON 不包含 token；前台任何页面不出现邮箱以外的账号信息。

GATE 06
性能预算

前台任一页面 Prisma 查询 ≤3；/logs 首屏 ≤2 且不含正文；/sitemap.xml ≤3。新增的馆藏卡与筛选栏不得突破。
