# 重构 V3 自测表（2026-11-16）

用途：本轮改动的功能里，凡是**需要登录或浏览器交互**的，AI 无法自行验证（dev 登录密码在 `.env`，AI 不读凭据）。
这张表把它们变成可照做的步骤；逐项点完即关闭全部验证缺口。

前置：`docker compose up -d` 起库 → `npm run dev` → 打开 `http://localhost:3000` → 右上「使用 GitHub 登录」。

记录方式：结果填 `通过 / 不通过 / 未测`，不通过时写一句现象（现象 → 位置 → 复现步骤）。
