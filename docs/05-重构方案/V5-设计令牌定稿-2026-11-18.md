## 四、使用规则（由实算结果定死，Phase 3 实施时照办）

1. **muted 不做小字**：`#8a8477` 三种底上均 <4.5:1。小于 24px（或 18.66px 粗体）的辅助文字一律
   `--ink-2`；muted 只用于大字（≥24px / ≥18.66px 粗体，3:1 达标）与纯装饰。
   色值保留原型原值（设计意图优先）；备选 `#726c60`（bg 上 4.86:1，但 bg-alt 上 4.42:1 仍不达标）
   **不采纳，仅留档待裁定**。
2. **warn 小字改 ink**：`#a97a1f` 小字 3.57:1 不达标。警示条文字用 `--ink`（warn-soft 底上 15.45:1），
   warn 本身只做图标、边框（非文本 3.57:1 ≥3）与大字。备选 `#8a6215`（5.10:1 / soft 上 4.60:1）
   **不采纳，仅留档待裁定**。
3. **line / line-2 只做装饰分隔线**（沿用 I073 装饰豁免先例，实算值仅留档不作门槛）；
   输入框、按钮等交互组件边界一律 `--ink-2` 或 `--accent`（均 ≥3:1），不用 line-2（1.41:1 / 1.93:1）。
4. **accent-soft / warn-soft 底上的文字**：亮色用 `--ink` 或 `--accent-dark`（5.72:1），
   不用 `--accent`（4.23:1）与 `--warn`（3.21:1）；暗色无此限制（5.36:1 / 7.31:1 均达标）。
5. **accent 用法维持 V5 §6.1 原文**（≥14px 粗体 / 边框 / 底色）：实算 4.83:1 虽已达普通文本 AA，
   本轮不借机放宽用法，放宽需负责人点名。
6. **焦点框**：`outline: 2px solid var(--accent)`，亮 4.83:1 / 暗 6.06:1，均 ≥3:1 ✅（V5 §6.4 判据达成）。
7. **搜索高亮 mark**：亮色 accent 底 + card 字（5.13:1）；暗色 `#6b3a2a` 底 + ink 字（7.26:1）。
