### 1.3 标签双轨（裁定 ② 的落地口径）

- **写入**：`normalizeTagList` 生成 `tagsKey`（小写 + 去 `@` + 去重），与 `tags` 同步落库。
- **展示**：一律用 `tags`（原始大小写）；`GitHub` 不会变成 `github`。
- **URL**：`/tags/<tagsKey>`（小写、URL 编码）。
- **兼容**：proxy 命中 `/tags/*` 时，若路径段含大写或与规范键不一致，且该键存在，
  返回 308 到小写规范地址（保留查询串）；不存在则照旧 404。
- **查询**：`hasPublishedTag` / `getLogFacets` / 筛选参数一律走 `tagsKey`，返回显示名时按 `tags` 回填。
- **验收**：`/tags/React` → 308 → `/tags/react`；页面标题显示 `React`；RSS 的 `<category>` 用显示名。

## 二、B0 两页规格

### 2.1 首页 `/`

**目标**：三秒内说清"这是谁、做了什么、最近在干什么"。

**结构**

```
导航（1200）
────────────────────────────────────────────
Hero
  display 标语（两行内）
  body 副标
  右侧：最近发布 2026-11-13
  ↓ 1px ink 线
馆藏条：10 个项目 · 13 条已发布 · 最近更新 2026-11-13 · RSS →
────────────────────────────────────────────
[01] 精选项目 --------------------------- 全部作品 →
  01  项目名  ·  产品 · 进行中 · 4 篇   2016-11-13
      一句摘要
[02] 档案状态 ---------------------------
  项目名              状态   日志数   最近
[03] 最新日志 --------------------------- 全部日志 →
  BEFORE/AFTER 时间轴 | 标题 / 经验总结 / 项目 · 标签
[04] 按主题 ----------------------------- 全部日志 →
  8 宫格
```

**规则**
- Hero 上留白 96px，下留白 64px；标语与副标间距 24px；标语与线之间 48px。
- 馆藏条用 hairline 上下各一条，条目间距 32px，数字用 mono 18px。
- 精选最多 3 条；零日志项目不进精选（沿用 `pickFeatured`）。
- 最新日志 3 条，标题 h3 20px；经验总结两行截断。
- 主题区块只显示 `count > 0` 的主题。

**状态**
| 状态 | 表现 |
|---|---|
| 空库（0 日志） | Hero 下直接给"还没有已发布日志"；三个区块只留标题与空态 |
| 加载 | 三段骨架（`LoadingRows`），hero 不骨架 |
| 数据异常 | `error.tsx` 兜底，页面不白屏 |

**验收**
- 1440/768/375 无横向滚动；首屏 Prisma 调用 ≤3。
- 键盘：跳转正文 → 导航 → 精选 → 最新；每个链接有可见焦点。

### 2.2 日志详情 `/u/[handle]/logs/[slug]`

**目标**：长文可读 + 内容可核对 + 可带走（打印）。

**结构**

```
档案 / 开发日志 / 项目名        ← Breadcrumbs（12px）
────────────────────────────────────────────
项目名（mono 11）  20px 标题    ← h1 32px
BEFORE 时间轴 → AFTER 时间轴
标签 · 约 7 分钟
────────────────────────────────────────────  1px ink + 1px（double）
BEFORE                                     ← SectionHead 01
  正文（720，宋体 18/1.85）
AFTER                                      ← 02
经验总结（棕左线引用块）                    ← 03
[AI 辅助生成 · 作者审校]
档案凭据卡（哈希 / 时间 / 复制 / 如何核对）
← 上一篇     下一篇 →
相关阅读（3 条）
目录（桌面右栏 sticky / 移动折叠）
```

**规则**
- 面包屑：项目名指向 `/u/[handle]/projects/[slug]`；当前页不可点。
- 区块头用 `SectionHead`（编号 01/02/03 + 中文名），不改写作者标题。
- 经验总结用 2px 棕左线 + 16px 左内边距，纸白底不填充。
- 代码块：语言标签 + 复制；不做高亮。
- 图片：点击开灯箱。
- 印章区保留 `Seal`，位置在正文之后、相邻导航之前。
- 目录：≥2 个标题才渲染（沿用 `extractToc`）。

**状态**
| 状态 | 表现 |
|---|---|
| 摘要缺失 | 保留告警卡（现状），不静默 |
| 无 AFTER | 不渲染 AFTER 区块，目录只算 BEFORE |
| 无标签 | 不渲染标签行 |
| 图片加载失败 | `alt` 文本可见，不撑破布局 |
| 打印 | 导航/目录/进度条/复制/灯箱隐藏；印章保留 |

**验收**
- 行宽 720px ±0；正文与页面标题不出现两个 h1（正文 h1 降级为 h2，现状保留）。
- 灯箱：Esc 关闭、焦点归还、底衬点击关闭。
- 代码块：复制成功 2 秒回显；无 JS 时仍可选中复制。
- 打印预览：3 页内（13 条中位长度日志），无 UI 元素。

## 四、状态矩阵（全站统一）

| 场景 | 规则 |
|---|---|
| 空（0 条） | 一句事实 + 一个出口（不清空搜索框以外的上下文） |
| 加载 | 骨架行，不用"加载中…"文字（除按钮内） |
| 错误 | 错误码 + 一句人话 + 重试；不暴露堆栈 |
| 极端数据 | 超长标题两行截断；0 标签不渲染空行；超长标签串换行不溢出 |
| 权限 | 未登录进后台 → 登录页并回跳；无权限资源与不存在同表现 |

## 五、文案口径

- 不用"存证""法律效力""不可篡改"这类承诺性词汇；用"内容摘要""可核对是否被改动"。
- 计数用阿拉伯数字 + 量词：`13 条已发布`，不写 `13 published`。
- 英文只保留系统专有标识：BEFORE / AFTER / LAITY / RSS / SHA-256。
- 空态不卖萌、不写"哎呀"；错误不说"抱歉"超过一次。
